# TEGIO restoran tizimi

Restoran va kafe egalari hamda kassir uchun ilova (biz.tegio.uz). Flutter Web. Hozir qobiq: navigatsiya va bo'limlar ro'yxati.

Bu repo asosiy `tegio` monoreposidan ajratilgan. Umumiy kod `packages/tegio_core` nusxasi sifatida shu yerda turadi.

```bash
flutter pub get
```

```bash
flutter run -d chrome
```

```bash
flutter test packages/tegio_core
```
